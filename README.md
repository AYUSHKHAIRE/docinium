
# Docinium

This is the high level python library to help developers to manage multiple browser sessions in multiple docker containers .

* This library utilizes [django](https://www.djangoproject.com/) as its internal communication manager .
* for real time streaming , communication and instruction , it use [django channels](https://channels.readthedocs.io/en/latest/) .
* I am planning to use [docker SDK](https://docker-py.readthedocs.io/en/stable/) to manage docker containers .
* as a browser , I am planning to use [firefox](https://www.mozilla.org/en-US/firefox/new/) .
* to manage browser sessions , I am planning to use [selenium](https://www.selenium.dev/) .
